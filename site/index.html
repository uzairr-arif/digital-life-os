The loop is the product.

Most tools stop at a scan report. dlos closes the circle every time you run it, and keeps the receipts.

Discover

Add the domains you own. Scope is explicit and confirmed, never assumed.

Understand

Every finding explains what was observed, why it matters, and how confident the tool is.

Act & verify

Fix it, then re-scan. dlos compares evidence and marks the finding resolved.

Build history (the receipt)

New, recurring, resolved, regressed. Your security story is recorded, append-only.

Findings that show their work.

No opaque 82/100 scores. Every finding carries the same contract, so you can check the tool's reasoning by hand.

HIGH  HTTP does not redirect to HTTPS
rule https-redirect · score 60 · status open
Observed: The plain-HTTP endpoint responded directly with content, no redirect.
Impact:   Anyone on the network path can read or alter that traffic.
Fix:      Answer http:// with a permanent 301 redirect to https://.
Verify:   Re-run dlos scan; the check moves to verified when fixed.
Real output format. Failed checks are listed as inconclusive, never dressed up as findings.
observation
What the tool actually detected, in plain language.
evidence
The raw check result, redacted, with a timestamp.
impact
What the issue could mean in practice, not a scare headline.
confidence
How certain the interpretation is. Uncertainty is labeled, not hidden.
recommendation
The next concrete action for this exact finding.
verification
How to test the fix. The next scan runs it for you.
history
Whether the issue is new, recurring, resolved or regressed.

Everything it checks. Nothing it doesn't.

A deliberately small set of reliable, deterministic checks. Deterministic beats impressive.

HTTPS http.*

  • redirect
  • reachability

TLS tls.*

  • expiry window
  • trust + hostname
  • protocol version

Email email.*

  • SPF + all-qualifier
  • DMARC policy
  • DKIM selectors

HTTP headers http.headers

  • strict-transport-security
  • content-security-policy
  • x-content-type-options
  • x-frame-options
  • referrer-policy
  • permissions-policy

DNS dns.*

  • record inventory
  • CAA policy

All checks are passive and read-only: no brute force, no exploitation, no port scanning. Cookie values are never stored. Failed checks are reported as errors, and the rules stay silent rather than guess.

Run your first scan.

  • installNode 22.13+, pnpm, one clone.
  • addA domain you own. The --confirm flag is the scope contract.
  • scanEight passive checks, one report, zero uploads.
  • verifyFix, re-scan, and watch the finding flip to resolved.

Everything lives in SQLite on your machine. No account, no cloud, no telemetry.

$ git clone https://github.com/uzairr-arif/digital-life-os
$ pnpm install
# confirm you own the domain, always
$ pnpm dlos asset add example.com --confirm
$ pnpm dlos scan example.com
+ 6 checks verified
$ pnpm dlos findings
